# 注文から3日後の「準備してます」メールの型

差し込み: `{名前}` `{番号}` `{発送目安}`（名前は注文データから。姓名の逆は namae_check が直す）
店名・署名・アドレスは自分のものに書き換えて使う。

## 件名

```
【ショップ名】ご注文 {番号} の準備状況のお知らせ
```

## 本文

```
{名前} 様

ショップ名 カスタマーサポートでございます。

このたびはご注文いただき、誠にありがとうございます。
ご注文 {番号} の、いまの状況をお知らせいたします。


■ お支払い

ご入金を確認しております。
お客様の側でのお手続きは、すべて完了しております。


■ 発送

ただいま準備を進めております。
ご注文から発送まで {発送目安} ほどいただいております。

発送が済みましたら、追跡番号をあらためてメールでお送りします。


■ ご不明な点がありましたら

このメールに、そのままご返信ください。

ショップ名 カスタマーサポート
support@example.com
```

`{発送目安}` は実測（注文日→発送日）から決める。倉庫が詰まったら取り直す。
