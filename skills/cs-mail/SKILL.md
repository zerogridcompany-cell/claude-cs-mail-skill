# cs-mail — CS受信箱をClaudeが読んで・送って・確かめる

## 何ができるか
| やること | 道具 |
|---|---|
| 受信箱を読む・検索する | `scripts/csmail.py list "<Gmail検索>" [--json]` |
| 1通を全文で開く | `scripts/csmail.py open "<件名の一部>" "<検索>"` |
| CSアドレスから1通送る＋送信済みで確認 | `scripts/csmail.py send --to X --subject Y --body-file Z [--dry]` |
| 購入者に同じ文面を一斉に（台帳で二重防止） | `scripts/ikkatsu_mail.py <文面.md> <宛先.json> <台帳.json> [--send]` |
| 注文からN日後の自動メール | `scripts/junbi_mail.py --orders-json <file> [--send]` |
| 姓名の逆を直す（宛名用） | `scripts/namae_check.py <名> <姓>` |
| 専用ブラウザの起動・状態 | `scripts/seat.sh start / status / stop` |

## しくみ（1枚で）
```
[CS受信箱(Gmail)] ─読む→ [自分の客だけ選ぶ] ─→ [もう返事した？] ─→ [本人に報告]
       ▲                     ▲ Shopifyの注文アドレス                  │
  [送信済みトレイ] ←確かめる─ [送る] ←────── 本人の「送って」 ←────────┘
```
- 公式のGmail連携は**自分個人のアドレスしか見えん** → 共有のCS箱は、Claude専用ブラウザで人と同じ画面を開いて読む
- 専用ブラウザにはCSアドレス**だけ**でログイン → 送信は必ずCSアドレスから出る（個人アドレスから誤送信せん）

## はじめの設定（1回だけ）
1. `pip3 install websocket-client`
2. `scripts/seat.sh start` → 開いた窓でCSアドレスのGmailにログイン（以後は覚えとる）
3. `scripts/csmail.py list` で一覧が出ればOK

## 🔴 守ること（実際に事故った所）
1. **客に送る前に、文面を人に見せて「送って」をもらう。** 「送って」は中身のOKで、手段のOKやない。頼まれた手段が使えんかったら、別の手段で撃たず止まって選択肢を出す
2. **返金・キャンセルのボタンは「押して」と言われた1件だけ。** 押したら `kind:REFUND` が `SUCCESS` か見る（`PENDING` はまだ客に戻ってへん）
3. **自分のブランドの客だけ拾う。** 共有箱には他ブランドが混ざる。判定は「注文のアドレスと一致」か「ブランド名が入っとる」。**注文番号の桁では判断せん**
4. **宛名は注文データから取る。** メールの表示名は漢字を読み違える。姓名の逆（50件中2件）は `namae_check` で直す。決めきれんかったら「お客様」
5. **返事済みか必ず見る。** 送信済みトレイで「客のメールより後に出したか」。見んと二重に返事する
6. **送ったら3段で確かめる。** ①送信ボタンが押せた ②送信済みトレイに**件名が完全一致**の1通がある（頭だけで照らすと前のメールで誤判定する）③台帳に書く。押せたけど確認できんかった分も台帳に残す（残さんと次回もう1通飛ぶ）
7. **弾かれたメールも見る。** `csmail.py list "from:mailer-daemon newer_than:1d"`。アドレス違いの客は注文確認も届いてへん
8. **ログアウト中に「0件」と答えん。** csmail はログアウトを検知したら exit 3 で止まる
9. **タブが溜まると固まる。** 30枚を超えたら `seat.sh stop && seat.sh start`
10. **ファイルは添付できん。** 説明書などは、ページにしてリンクで送る

## 自動で回すなら（例）
- 見回り（朝・夕）：`examples/mimawari_prompt.md` を launchd/cron から `claude -p` で。**客には送らん**設定にしておく
- N日後メール：毎日1回 `junbi_mail.py --send`。注文は Shopify から「未発送・支払い済み・古い順」で取る
- ⚠️ Macが寝とったら走らん

## 使う時の順番
1. `seat.sh status`（席が生きとるか・タブの数）
2. 読む → 自分の客だけ選ぶ → 返事済みか見る
3. 文面を作る → 人に見せる → 「送って」
4. 送る → 送信済みトレイで確認 → 台帳 → 弾かれメール確認
5. 結果を表で報告（送れた数・失敗・弾かれ）
